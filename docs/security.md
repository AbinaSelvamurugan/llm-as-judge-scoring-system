# Security, privacy and retention

**Outbound data:** Live `ClaudeJudge` sends the original question, candidate answer, relevant reference answer/evidence, and rubric/criterion definitions to the Anthropic API. Any sensitive information contained in these fields goes to the provider. Obtain authorization, apply data minimization and conduct a data handling review before sending. No API traffic occurs during schema/metrics tests or blind human annotation. Set `JUDGEBENCH_OFFLINE=1` for fail-closed no-paid-API mode.

**Credentials:** `ANTHROPIC_API_KEY` is read only from the process environment. `.env` files are excluded from Git and are not auto-loaded. Provider errors are classified and recorded without request bodies, stack traces or raw provider text. The UI shows bounded safe messages. Avoid logging prompts or credentials. If multiple users share a machine, limit filesystem access to SQLite and exports.

**Access and retention:** For demo/local use, dashboard does not enforce login. For controlled annotation studies set two *different* strong tokens (`JUDGEBENCH_ANNOTATOR_TOKEN`, `JUDGEBENCH_REVIEW_TOKEN`) plus authenticated TLS reverse proxy; these are not a comprehensive access-control system. Annotator pseudonyms are caller-provided, not identity verified. Study administrator must maintain identity mapping separately. SQLite stores raw candidate text, scores, free-form human comments and adjudication reasons in cleartext on disk; encrypt disk/backups and restrict permissions. Delete datasets by deleting archived exports and the SQLite database (or applying a supervised row-delete migration while honoring relational dependencies). No scheduled retention or deletion automation is included. The tool does not guarantee compliance with any specific privacy regulation.

**Untrusted content:** Candidate answers are JSON-encoded user data, never system instructions. API output always receives Pydantic + rubric semantic validation. Uploaded CSV/JSONL is bounded, parsed (not executed), and invalid rows rejected. The CLI accepts an explicit output path—restrict its execution to a trusted user; the dashboard never accepts raw filesystem paths for imports or exports. Do not put the dashboard on an unauthenticated public host.
