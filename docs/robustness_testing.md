# Bias and robustness experiments

CLI/UI experiment commands call the configured Claude service. For `verbosity`, `presentation`, `injection` and `attribution`, supply an alternate answer explicitly and retain matched original task and evidence. Ensure content equivalence manually where required; otherwise grade differences may reflect legitimate rubric changes, not bias. `reference` evaluates the same answer with versus without supplied answer/evidence (use reference policies that allow omission). `repeat` calls the identical content multiple times and quantifies the number of unique scores and literal rationale strings.

The persistence table records original, altered, model, rubric and per-repetition score/rationale pairs with observed token counts. Reports and the dashboard display only conducted experiments, never simulated results. These are exploratory paired comparisons, not causal identification without controlled equivalence, randomization where appropriate, adequate power and held-out sampling.

For **missed fabricated facts**, independently mark factually incorrect or unsupported-claim cases through human review and inspect whether the factual/grounding Claude grade was nevertheless high. For **relevance-versus-correctness confusion**, sample high-relevance/low-correctness responses and audit joint ratings. For **model attribution**, anonymize generator names, compare matched quality strata and document selection bias. For **position bias**, user-provided variants can change formatting or order of presented content; this is not a full pairwise A/B order randomization engine.
