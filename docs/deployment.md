# Deployment

Use an approved Python 3.11–3.14 environment. Install `pip install -r requirements.txt`, configure API key and database path and run `judgebench init`. Launch with `streamlit run app/streamlit_app.py --server.address 127.0.0.1` and access through a trusted authenticated reverse proxy if remote access is necessary. Set `JUDGEBENCH_ANNOTATOR_TOKEN` and `JUDGEBENCH_REVIEW_TOKEN` in the server's secured secret manager for role separation; do not share reviewer credentials with raters. Mount SQLite on a persistent restricted-access filesystem, schedule backups outside the application, and run only one paid batch worker at a time. This implementation is an offline-friendly reference study workbench, not a hardened multi-tenant SaaS; provider credentials, data governance and SDK/UI compatibility must be verified before deployment.
